## 美股列表

---

接口：us\_basic  
描述：获取在美主要交易所挂牌证券的基础信息列表，包含证券代码、中英文名称、所属交易所、证券类别及上市退市日期，按证券粒度构建，可识别 ADR、GDR、普通股与优先股四类证券。  
限量：单次最大6000，可分页提取。  
**注：美股代码存在代码复用，变更，多市场交易等，可能存在数据重复情况，需要加入上市状态判断数据情况**  
积分：120积分可以试用，5000积分有正式权限

**输入参数**

| 名称 | 类型 | 必选 | 描述 | 示例 |
| --- | --- | --- | --- | --- |
| ts\_code | str | N | 股票代码 | AAPL（苹果） |
| classify | str | N | 股票分类 | ADR-美国存托凭证；GDR-全球存托凭证；EQ-普通股；PF-优先股 |
| list\_stauts | str | N | 上市状态 | L上市D退市P暂停上市 |
| exchange | str | N | 交易所 |  |
| offset | str | N | 开始行数 | 1：第一行 |
| limit | str | N | 每页最大行数 | 500：每页500行 |

**输出参数**

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ts\_code | str | Y | 美股代码 |
| name | str | Y | 中文名称 |
| enname | str | N | 英文名称 |
| classify | str | Y | 分类:ADR-美国存托凭证；GDR-全球存托凭证；EQ-普通股；PF-优先股 |
| list\_status | str | N | 上市状态 L上市 D退市 G过会未交易 P暂停上市 UN未上市 |
| list\_date | str | Y | 上市日期 |
| delist\_date | str | Y | 退市日期 |
| exchange | str | N | 交易所 |

# **代码示例**

```
pro = ts.pro_api()

#获取美股某只股票基础信息
df = pro.us_basic(ts_code='AAPL')

#获取默认美国股票基础信息，单次6000行
df=pro.us_basic(fields='ts_code,classify,list_date,list_status,exchange')
```
